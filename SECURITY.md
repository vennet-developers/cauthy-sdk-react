# Security

Report a vulnerability privately through GitHub Security Advisories on this repository
(Security → Report a vulnerability). Do not open a public issue.

We answer within 72 hours, and we patch the current 1.x and the previous minor release.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x (current) | Yes: fixes and security patches |
| The previous minor of 1.x | Yes: security patches only |
| Anything older | No: upgrade to the current 1.x |

## Time to fix

| Severity | Patch released within |
| --- | --- |
| Critical | 7 days of the report being confirmed |
| High | 30 days |
| Moderate and low | The next regular release |

We credit reporters in the advisory unless they ask us not to.
